# 产品路线图

> 社易管（SmartSociety）：面向社会团体的数字治理与多端协同管理平台。

---

## 产品核心定位

社会团体内部**纯管理端**——以统一组织数据为底座、以事件和规则为驱动、以流程自动化为执行机制、以全域感知为管理入口，由 Web + Android + HarmonyOS 三端协同工作。

---

## 产品边界

**核心用户**：会长、秘书长、财务负责人、理事、监事、秘书处/行政人员等授权管理人员。

**核心业务**：组织档案、人员/会员、组织架构、治理机构、任期/换届、会议/议案/决议、决议执行、项目/任务、审批/工作流、财务/预算、合同/档案/证照、合规、数据治理、风险/预警、组织分析、自动化治理。

**明确不做**：公众活动报名、社交/社区、朋友圈、即时社交、内容社区、活动营销、公众服务平台、普通会员消费服务。

---

## 三端定位

| 端 | 定位 |
|---|---|
| **Web** | 组织级管理控制台——复杂治理、配置、批量处理与分析中心（数据治理、主数据管理、权限配置、规则配置、批量导入/导出、财务报表、审计检索） |
| **Android** | 移动管理与执行端——随时感知组织状态 + 随时处理管理事项（驾驶舱、待办、审批、风险处置、决议执行、全域搜索、离线工作） |
| **HarmonyOS** | 与 Android 共享业务模型的移动管理端——数据模型、身份、权限、业务状态机、事件模型、云端业务逻辑、自动化规则完全一致，UI 结合鸿蒙设备能力优化 |

## 近期方向

推进测试优化与打包上架；接入真实 AGC 网关完成三端联调验收（幂等并发、correlationId 全链路、规则停用联动）；基础数据和规则体系稳定后再建设智能总结、风险辅助分析等高级能力。

---

## 核心架构原则（十项）

十项核心设计原则（数据先于页面、业务先于客户端、事件先于人工操作、感知必须连接行动、自动化必须可解释、高风险决策必须保留人工授权、Cloud DB 是数据底座不是全部后端、Cloud Hosting 是 Web 托管能力不替代后端服务、移动端做执行 Web 做治理配置、不追求功能数量追求治理闭环）详见 [docs/architecture.md](architecture.md) §六。

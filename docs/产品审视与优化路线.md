# 产品功能审视与优化路线

> 基于当前代码库（Flutter + HarmonyOS + AGC Serverless）的全面审视。
> 本文档分为：现状功能清单、已识别的问题与风险、体验/性能/安全优化、新增功能路线、UI 设计语言。

## 二、已识别的问题与风险

### 数据与一致性
- **通知已读状态仅存本地**：换设备或重装后已读标记丢失；应上云（Notice.isRead 已同步字段，但 markRead 未入队）。
- **同步队列为 last-write-wins**：多端同时编辑会互相覆盖，无冲突提示；离线积压时云端拉取可能回退本地新数据（flush 顺序已有保护，但仍缺版本号）。
- **get-all-data 全量拉取**：>1000 条已分页，但组织数据量大时单次响应体积大、切换组织慢；建议按模块分页/增量拉取。
- **财务数据云端直查**：与成员/项目/通知的本地缓存模式不一致；弱网时财务不可用（有意为之，但体验需说明）。
- **财务报表实时计算**：结账后仍可修改该年度凭证，报表会随修改变化；无会计锁定期间。

### 权限与安全
- **业务级权限不完整**：多数云函数只校验“组织成员”，未按角色限制（例如普通成员可查看全部财务单据、可看全部成员手机号）；成员角色仅前端拦截。
- **钉钉凭证明文存储**（OrgSettings.dingtalkClientSecret）：应加密或接入 KMS/密钥服务。
- **云函数认证**为 apigw-client，缺统一审计日志。

### 性能
- 成员列表全量加载到内存再筛选；千人以上组织需服务端分页/搜索。
- 财务统计每次全量拉取后内存聚合；年度数据大时建议按科目/期间聚合查询。
- 审批引擎在节点推进时全量拉取成员按角色解析处理人，大组织下偏重。

### 体验
- 首页即“成员列表”，无工作台/数据看板。
- UI 为 M3 默认风格，缺少品牌设计语言（见第六节）。
- 无骨架屏/统一加载态；部分页面刷新依赖手动。
- 无搜索/筛选的统一组件（成员有，项目/通知没有）。
- 通知无“全部已读”、无分页。

## 三、体验优化（近期）

1. **工作台首页**：问候 + 统计卡（成员/进行中项目/未读通知/财务待办）+ 快捷入口 + 最近动态。
2. 通知：全部已读、未读筛选、已读状态上云。
3. 列表：项目/通知增加搜索与状态筛选；统一下拉刷新与骨架屏。
4. 审批待办：角标推送/本地提醒；审批意见必填开关。
5. 财务：凭证附件拍照上传（云存储）、预算超额预警、年度切换器统一。
6. 成员：Excel 导入导出、头像（从华为账号/自定义）、按部门分组展示。

## 四、性能与安全优化（中期）

- 云函数分页/聚合查询（成员、财务、通知），避免全量拉取。
- 服务端角色权限矩阵：成员/项目/财务按角色（社长/部长/普通成员）限制读写。
- 钉钉凭证加密存储；全量操作审计日志（谁在何时改了什么）。
- 数据版本号（updatedAt + 冲突检测），多端编辑冲突提示。
- 财务结账锁定期：结账后该年度凭证只读，需“反结账”方可修改。
- 凭证编号自动流水（按年度），防重号。

## 六、UI 设计语言（对标钉钉/飞书）

### 原则
- **信息优先、弱化装饰**：浅灰画布（#F5F6F7）、白色卡片、1px 极浅边框 + 极轻阴影，层次靠间距而非描边。
- **统一圆角与间距**：8pt 基准，卡片 16、控件 12、徽章胶囊。
- **克制的品牌色**：主色仅用于关键操作与选中态；功能色语义化（成功 #00B96B、警告 #FF8800、错误 #F54A45、信息 #3370FF）。
- **清晰的字级**：标题 17 加粗 / 正文 15 / 辅助 13（灰 #8A9099）。
- **图标化引导**：空状态图标放入浅色圆底容器；快捷入口使用宫格图标。
- **暗色模式**：跟随系统，卡片/画布保持同一套对比规则。

### 落地范围（已随本迭代实施）
- 全局 Theme：画布背景、卡片（白底+边框+轻阴影）、底部导航（白底+品牌选中色）、AppBar（与背景同色）、输入框（浅灰填充/聚焦白底+品牌描边）、按钮（品牌实心、大圆角）、对话框与浮动 SnackBar。
- 核心组件升级：AppCard、StatusBadge（语义化胶囊）、AppEmptyState/EmptyView（图标圆底）、MemberAvatar（品牌渐变）、Toast/ConfirmDialog 样式。
- 新增工作台首页：统计卡网格 + 快捷入口宫格 + 最近动态，底部导航改为 5 栏（首页/成员/项目/通知/财务）。
